# Packetra Security Policy

## Infrastructure Security

Packetra operates infrastructure in Finland under strong EU data protection regulations.  
All servers are deployed in renewable-energy powered datacenters with network-level DDoS protection.

Dedicated servers use Software RAID-1 by default for disk redundancy.

## Account Protection

- Two-Factor Authentication (2FA) is available for client accounts.
- Secure client portal powered by WHMCS.
- Free SSL certificates included on hosting plans.
- Regular backups included on Shared and WordPress hosting.

## Network Protection

- DDoS mitigation enabled across infrastructure.
- Firewall and server hardening practices applied.
- Continuous monitoring of uptime and services.

## Responsible Disclosure

If you discover a security vulnerability, please report it to:

security@packetra.com

We take all security reports seriously and aim to respond promptly.
